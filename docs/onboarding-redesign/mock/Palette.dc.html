DESIGN SYSTEM · PROPOSAL

One green, one yellow, three macros.

The App Store screenshots already found the brand: near-black, a leaf green for progress and a sun yellow for the main action. The app’s theme hasn’t caught up yet. These tokens make the onboarding, the store page and the app look like one product.

WHAT’S INCONSISTENT TODAY

Three “primary” colours
Light mode uses black, dark mode uses Material blue #90CAF9, and the accent is Material green. Blue appears nowhere in the brand.
Material defaults for macros
Stock red/blue/orange 400s. The fat orange sits close to the yellow add button, so they compete.
Aa Aa Aa Aa
Four typefaces
Poppins, Onest, Inter and Roboto all ship. The newer screens (adaptive, check-in) already moved to Onest.
2.0 : 1
Contrast fixes by hand
The dark accent needed an onAccent patch and the adaptive page hard-codes #2E6A3D. Tokens should carry those pairs.

MOTION

Settle cubic-bezier(.2,.8,.2,1) · 250–700 ms
Screen content rising in, bars and charts filling. Flutter: Cubic(0.2, 0.8, 0.2, 1)
Pop cubic-bezier(.2,.9,.3,1.3) · 350 ms
Checks, tags, success states. A small overshoot, never a bounce loop.
Draw 1.2–1.6 s · ease-in-out
Projection lines and rings. Data is always drawn, never faded in.
Stagger 80 ms between siblings. Every animation respects Reduce Motion: the end state shows instantly. Use Lottie only for moments that need layered motion (plan ready, streaks). Charts and rings stay CustomPainter so they show real numbers.
